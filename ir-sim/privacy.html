개인정보처리방침

IR 라인트레이서 시뮬레이터 (HI-RACE 1/10 IR 라인트레이서 팀) · 시행일 2026-10-26

1. 수집하는 정보

시뮬레이션 기능은 로그인 없이 쓸 수 있으며, 이때는 어떤 개인정보도 서버로 보내지 않습니다. 차량 설정과 코드는 사용자의 브라우저(localStorage)에만 저장됩니다.

"공유 차고"에 차량을 올리기 위해 Google로 로그인하는 경우에만 다음 정보가 저장됩니다.

  • Google 계정 식별자, 이메일 주소, 표시 이름 (로그인 처리용)
  • 사용자가 직접 올린 차량 이름, 차량 레이아웃(JSON), 아두이노 코드, 올린 시각

2. 이용 목적

  • 로그인한 사용자를 구분하고, 자신이 올린 차량만 수정·삭제할 수 있게 하기 위해
  • 공유 차고 목록에 올린 사람의 이름을 표시하기 위해

그 밖의 목적(광고, 분석, 제3자 판매)으로는 쓰지 않습니다.

3. 공개 범위

공유 차고에 올린 차량 이름, 레이아웃, 코드, 올린 사람의 표시 이름은 이 페이지를 여는 누구나 볼 수 있습니다. 이메일 주소는 목록에 표시하지 않습니다.

4. 보관 위치와 기간

정보는 Supabase(대한민국 서울 리전)에 저장됩니다. 사용자가 차량을 삭제하면 해당 데이터는 즉시 삭제되며, 계정 정보는 삭제 요청 시 지웁니다.

5. 삭제 요청

올린 차량은 시뮬레이터의 공유 차고에서 직접 삭제할 수 있습니다. 로그인 계정 정보 삭제는 GitHub 저장소 이슈로 요청하거나 팀 관리자에게 알려 주세요.

6. 쿠키 등

로그인 상태 유지를 위해 브라우저 저장소에 인증 토큰이 저장됩니다. 로그아웃하면 지워집니다.
